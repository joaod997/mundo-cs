# Mundo CS 🎮

## Sobre o projeto

O Mundo CS é um site desenvolvido para apresentar informações sobre o jogo Counter-Strike 2. O objetivo é mostrar um pouco sobre o jogo, seus modos e seu funcionamento.

## Conceitos aplicados

- **Usabilidade:** menu simples para facilitar a navegação.
- **Experiência do Usuário (UX):** organização das informações para tornar o site fácil de utilizar.
- **Acessibilidade:** textos de fácil leitura e descrição alternativa na imagem.
- **Responsividade:** adaptação do conteúdo para telas menores, como celulares.

## Escolhas de design

Foram utilizadas cores azul escuro, branco e cinza claro para deixar o site simples e organizado. As páginas possuem o mesmo padrão visual e links para facilitar a navegação.

## Integrante e tarefas

**Integrante:** Trabalho individual.

**Tarefas realizadas:**
- Criação das páginas HTML.
- Desenvolvimento do estilo com CSS.
- Escolha das cores e imagens.
- Organização dos conteúdos.
- Criação dos links de navegação.
- Aplicação de responsividade.
- Preparação do projeto para publicação.
